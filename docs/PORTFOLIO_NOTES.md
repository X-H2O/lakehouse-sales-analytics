# Portfolio Notes

## Suggested GitHub Description

Beginner-friendly sales analytics data engineering project with batch processing, streaming processing, lakehouse storage, ClickHouse serving, and Metabase dashboards.

## Suggested README Tagline

A single-machine practice project that helps beginners understand how simulated business orders become historical and realtime sales analytics dashboards.

## What This Project Demonstrates

- Ability to learn and explain a modular data platform.
- Understanding of ODS, DWD, DWS, ADS, and realtime serving layers.
- Practical experience with Spark batch processing and Spark Structured Streaming.
- Integration of message queues, object storage, analytical databases, and BI tools.
- Ability to build a small business application that produces data for analytics.
- Ability to document system architecture and metric definitions.

## What To Show In A Portfolio Or Application

Recommended screenshots:

- architecture diagram;
- Metabase dashboard;
- simulated business frontend;
- ClickHouse realtime table;
- data quality check output.

Recommended demo:

1. Run batch pipeline and show historical dashboard cards.
2. Start the streaming job.
3. Submit a new order in the business frontend.
4. Show the order appearing in ClickHouse realtime tables.
5. Refresh Metabase and show minute-level metrics updated.

## Honest Scope Statement

This is a single-node educational practice project. It demonstrates architecture, data flow, and integration logic rather than production-scale throughput or high availability.
