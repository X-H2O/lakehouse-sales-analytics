# Project Scope

This repository is a beginner-friendly educational practice project built during undergraduate study.

## What It Is

- A local learning project that simulates a sales analytics data platform.
- A demonstration of batch processing, streaming processing, lakehouse storage, analytical serving, and dashboard visualization.
- A reproducible reference for beginners who want to understand an end-to-end data engineering workflow.
- A project that can also be used as portfolio evidence because it shows practical system integration work.

## What It Is Not

- It is not a production-grade deployment.
- It is not a high-concurrency benchmark.
- It does not include enterprise security, access control, lineage governance, or disaster recovery.
- It should not be described as a completed commercial big data platform.

## Why It Is Useful

The project makes the boundaries of a modern data platform visible:

- business applications generate operational records;
- source databases persist business state;
- batch jobs build historical analytical layers;
- streaming jobs process recent events;
- analytical databases serve dashboard queries;
- BI tools present metrics to users.

This makes the project useful for two purposes: learning data engineering step by step, and showing practical engineering ability in a project portfolio.
